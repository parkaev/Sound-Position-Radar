# Sound Position Radar

Визуальный индикатор направления звука для игр: показывает на экране, **с какой стороны**
раздался громкий звук — выстрел, шаги или щелчок пули. Помогает быстрее считывать звуковую
картину матча, в том числе игрокам, которым сложно ориентироваться по звуку.

Программа слушает **системный звук** (весь выход устройства или звук конкретного процесса)
и подсвечивает направление события у краёв экрана.

> **Это не чит.** Программа не читает память игры, не внедряется в процесс и не эмулирует
> ввод — только публичные аудио-API Windows (тот же уровень, что у OBS «Application Audio
> Capture»). Она показывает ровно то, что игрок слышит на слух, но в визуальном виде.

## Возможности

- **Захват звука конкретного процесса** (WASAPI process loopback) или всего устройства;
- Профиль **DayZ** (откалиброван по записям выстрелов: ошибка направления ~2°) и
  универсальный constant-power профиль;
- Детекция «выделяющихся» звуков: адаптивный фон по 5 частотным полосам, раздельный
  буст для вч-щелчков пули;
- Два пресета оверлея: **Дуги** (секторы у краёв) и **Кромка** (градиентное свечение
  вдоль краёв экрана);
- Цвет индикации: по близости (зеленоватый — дальше, тёмно-красный — очень близко),
  по громкости или постоянный;
- Гибкая настройка оверлея: непрозрачность, размер, ширина реакции, скорость затухания,
  скрытые зоны — всё с шагом 1 и ручным вводом значений;
- Глобальный хоткей включения/выключения оверлея (работает поверх игры);
- Журнал событий (JSONL) и запись сырого WAV для диагностики.

## Установка

Скачайте `Sound Radar.exe` со страницы
[Releases](https://github.com/parkaev/Sound-Position-Radar/releases) и запустите —
установка не требуется (Windows 10 19041+ / Windows 11).

## Быстрый старт

1. Выберите источник: процесс игры (в списке сверху — процессы, которые сейчас играют звук)
   или всё устройство.
2. Выберите профиль игры (DayZ / Универсальный) и нажмите **Старт**.
3. Включите «Показывать поверх игр» — оверлей появится у краёв экрана
   (игра должна быть в оконном режиме или «окно без рамки»).
4. Настройте порог/мин. громкость (подсказки при наведении) и цвет под себя.

## Ограничения

- Стерео-звук не различает «перед/зад» — индикация 180°. Если игра умеет 5.1/7.1,
  включите «360°: захват 8 каналов» — зад будет определяться.
- В полноэкранном исключительном режиме оверлей не виден — используйте borderless.
- EULA отдельных игр может запрещать сторонние оверлеи — проверьте правила вашей игры.

## Сборка из исходников

Требуется .NET SDK 10:

```bash
dotnet build SoundRadar.slnx
dotnet test  tests/SoundRadar.Core.Tests/SoundRadar.Core.Tests.csproj
dotnet publish src/SoundRadar.App/SoundRadar.App.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

## Технологии

.NET 10 / C# / WPF, NAudio 3 (WASAPI), собственный DSP (FFT-1024, адаптивный фон,
детектор онсетов, калибровка панорамы). Тесты — xUnit, оффлайн-реплей на записях
реальных выстрелов.
